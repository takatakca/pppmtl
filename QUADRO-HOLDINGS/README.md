## Structure

- `Factures-Fournisseurs/` — factures de fournisseurs et abonnements à payer
  (bills, subscriptions, reçus de paiement).
- `Factures-Clients/` — factures et créances que nous avons envoyées à des
  clients (argent qui nous est dû).
- `REGISTRE-FACTURES.md` — une ligne par facture : date, vendeur, numéro,
  montant, devise, nom facturé, boîte d'origine, ID Gmail, ID Drive, chemin
  GitHub. Le nom facturé est noté pour retracer, mais le classement ne
  dépend pas de la marque.

## Où sont les vraies copies

  leur copie réelle est dans Drive, et le registre donne l'ID Drive de chaque

## Noms de fichiers

`AAAA-MM-JJ_vendeur_numero-facture_id-gmail_montant-devise.ext`
(ex. `2026-11-10_meta_391821941_1a1c5ec5_1-15USD.pdf`). « non indiqué »
signifie que l'information n'était pas dans le courriel — rien n'est inventé.

## Prudence

Aucun secret dans ces fichiers de notes : pas de numéro de compte bancaire,
pas de numéro de carte, pas de mot de passe, pas de code. Exception : un
fichier qui contient visiblement le numéro de compte bancaire de Pierre ou
une carte complète est conservé **Drive seulement** (pas de copie GitHub) et
marqué « Drive only » dans le registre.
